# 📡 MorseCode-Typer (Solo Leveling & Royal Sovereign Edition)

An interactive, responsive, and feature-packed Morse Code web suite created with clean vanilla JavaScript, Web Audio API synthesis, customizable mouse & keyboard keyers, interactive visual mnemonics, a dynamic procedural quiz engine, and custom dual themes.

---

## 🌟 Key Features

### 1. ⚡ Dual Theme Aesthetics
- **👑 Royal Sovereign (Light Mode):**
  - Crisp royal blue and clean white palette.
  - Regal styling with clean glassmorphism and gold sapphire accents.
  - Motivational Quote: *"Knowledge is the crown of the steadfast. Master the royal signal and conquer every realm." — King of States*
- **⚔️ Solo Leveling / Shadow Monarch (Dark Mode):**

---

### 2. 🔄 Real-Time Bidirectional Translator
- Real-time instant two-way synchronization between **Plain English Text** and **Morse Code**.
- Built-in Web Audio API tone player with adjustable **Speed (5 - 35 WPM)**.
- Integrated **Text-to-Speech (TTS)** voice reader for English output.
- One-click copy to clipboard, character & Morse signal counter, and instant reset.

---

### 3. 🖱️ Card 1: Mouse Morse Typer
- **Tapping Surface:** Large, tactile pad with visual ripple effects and audio tone synthesis.
- **Two Visual Display Boards:**
  - **Board 1 (Live Active Buffer):** Displays current dots and dashes being clicked (`. - -`), with an SVG circular progress ring visualizing the auto-commit countdown.
  - **Board 2 (Decoded Text Output):** Accumulates the decoded English text in real time.
- **Customizable Options:**
  - **Dual Click (Default):** Left Click = Dot (`.`), Right Click = Dash (`-`), Middle Click = Word Space.
  - **Single Click Timing:** Short click (< 200ms) = Dot, Long press (>= 200ms) = Dash.
  - **Custom Mapping:** Assign custom actions to Left, Right, or Middle clicks.
  - **Timing & Audio:** Configurable auto-commit letter pause gap, word pause gap, pitch frequency (Hz), volume, and waveform (Sine, Triangle, Square).

---

### 4. ⌨️ Card 2: Keyboard Morse Typer
- **Interactive Keyboard Input Pad:**
  - Visual glowing key-press indicators and instant audio feedback.
- **Three Input Modes:**
  - **Single-Key Timing (Default Spacebar):** Tap Spacebar for Dot, hold Spacebar for Dash.
  - **Dual-Key Mode:** `J` for Dot, `K` for Dash, `Space` for Word Space.
  - **Direct Character Mode:** Type `.`, `-`, `/`, and spaces directly.
- **Custom Keybinder:** Remap any physical key on your keyboard with the interactive key recording modal.

---

### 5. 📖 Card 3: Learn Morse Code by Visual Mnemonics
- **Visual Mnemonic System:** Maps every letter and number to intuitive shapes and phonetic memory hooks (e.g. `A` = Arch `.-`, `B` = Banjo `-...`, `S` = Snake `...`).
- **High-Definition Illustration Chart Modal:** View the complete visual mnemonic chart.
- **Letter Cards Grid:** Displays Morse patterns, visual dot/dash pills, audio playback, and an interactive **Practice This Letter** sandbox.
- **Filter & Search:** Filter by All Symbols, Letters (A-Z), Numbers (0-9), or Punctuation.

---

### 6. 🎯 Card 4: Dynamic Practice & Quiz Arena
- **Procedural Question Generator (No static hardcoding):**
  - **Morse ➔ Character (MCQ):** Identify letters from Morse code with smart confusing distractors (inverted patterns, off-by-one errors).
  - **Character ➔ Morse (MCQ):** Select the correct Morse pattern.
  - **Audio Tone ➔ Character:** Listen to real-time beeps generated by the Web Audio API and identify the signal.
  - **Interactive Tapping Box:** Physically tap the dots and dashes into the live buffer box using on-screen buttons, mouse, or keyboard.
- **Solo Leveling Rank Progression:**
  - 🔰 Novice Scout (0 - 69 pts)
  - 🛡️ A-Rank Operator (70 - 149 pts)
  - ⚔️ S-Rank Hunter (150 - 299 pts)
  - 👑 Shadow Monarch (300+ pts)
- High score and streak tracking saved locally in `localStorage`.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari). No build tools, package managers, or server installations are required.

```bash
# Clone the repository
git clone https://github.com/KoushikDesu/MorseCode-Typer.git

# Navigate into the project folder
cd MorseCode-Typer

# Open index.html in your default browser
start index.html
```
