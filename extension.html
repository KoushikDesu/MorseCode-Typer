Desktop Browser Extension

Compatible with Google Chrome, Microsoft Edge, Brave, Opera, and Kiwi Browser (Android).

  • 1 Download or clone the /extension folder from our repository.
  • 2 Open chrome://extensions (or edge://extensions) in your browser and enable Developer mode (top right toggle).
  • 3 Click Load unpacked and select the extension folder. Done! The floating ball will appear on every webpage you visit.

Universal Mobile Bookmarklet

Use on mobile phones (Safari on iOS, Chrome on Android, Samsung Internet) without needing an extension store!

  • 1 Bookmark any page in your mobile browser and name it "Morse Typer".
  • 2 Edit the bookmark's URL and paste the JavaScript code below:
javascript:(function(){var s=document.createElement('script');s.src='https://morcecodekt.vercel.app/extension/morse-injector.js';document.body.appendChild(s);})();
  • 3 Open any website, type "Morse Typer" in the address bar and tap the bookmark. The floating ball appears instantly!
